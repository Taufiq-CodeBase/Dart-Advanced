# Dart Practice — Advanced Examples

A collection of focused Dart examples for intermediate and advanced practice. Each file demonstrates a specific language feature or small algorithm and is intended for hands-on learning.

## Contents

- Examples in this folder:
  - `operator.dart` — operators and expressions
- Root examples (single-file scripts):
  - `dart_practice.dart`, `variables.dart`, `functions.dart`, `oop.dart`, `list.dart`, `map.dart`, `set.dart`, `date_time.dart`, `find_max.dart`, `input.dart`, `my_class.dart`

## Getting started

1. Install the Dart SDK (stable channel).
2. From the repository root, run an example:

```bash
# Run the operator example
dart run bin/operator.dart

# Run a root script
dart run dart_practice.dart
```

## Guidelines

- Keep examples short and focused (one concept per file).
- Use clear output and comments to explain intent.
- Prefer readability and reproducibility over clever tricks.
